# Visual Rule Builder

Node-based visual editor for creating feed assignment rules.

## Tech Stack

- **React 18** - UI framework
- **React Flow** - Node-based editor
- **Vite** - Build tool
- **CSS** - Styling

## Development

```bash
npm install
npm run dev
```

Access at: http://localhost:3000

## Features

- Drag nodes from sidebar
- Connect nodes with edges
- Configure node parameters
- Save/load rules as JSON

## Node Types

- **START** - Entry point
- **END** - Output
- **AND/OR** - Logic nodes
- **Conditions** - Text, Language, Post Type, Likes, Author, Media
