Geoapify OSM Locality Extracts

Download curated country-level datasets of cities, towns, villages, and hamlets derived from OpenStreetMap. Each archive contains NDJSON files grouped by place type plus matching administrative borders when available.

Visit Geoapify.com

What's inside each archive?

  • place_city.ndjson, place-town.ndjson, place-village.ndjson, place-hamlet.ndjson
  • One locality per line in NDJSON format with coordinates, bounding box, multilingual names, address metadata, and optional population
  • border objects embed the corresponding administrative relation geometry when a match is found
  • inferred_type highlights classifications derived from address hints instead of explicit place nodes

How to use

  • Stream the NDJSON files with tools such as jq -c '.' place_city.ndjson
  • Load data into databases via bulk importers that accept JSON lines
  • Need polygons only? Filter entries that contain a border field

Geoapify Place Details API

Surface richer metadata, media, and high-resolution boundary geometries by plugging the locality's osm_id and osm_type into Geoapify's Place Details endpoint: 

https://api.geoapify.com/v2/place-details?osm_id=240102374&osm_type=n&apiKey=YOUR_KEY

Swap the identifiers and API key for your own values. Boundary relations embedded under border can also be queried the same way to obtain full polygon geometry.
