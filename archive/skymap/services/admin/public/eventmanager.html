Scoring Configuration

Adjust these parameters to tune how events are ranked for map visibility. Changes trigger an immediate recalculation.

Weight for absolute RSVP count component. Higher = more weight on total RSVPs.

Weight for RSVP density component. Higher = more weight on RSVPs per hour. Should sum to 1.0 with Absolute Weight.

When enabled, uses sqrt(duration) for density calculation instead of linear division. Reduces penalty for longer events.

Cap the density component to prevent extremely short events from dominating. Leave empty to disable capping.

Minimum RSVP count required to compete when city is oversubscribed (only applies if "Apply Minimum When Oversubscribed" is enabled).

Only apply the minimum RSVP threshold when there are more events than the city's event limit. Prevents small events from being filtered out unnecessarily.

How Scoring Works

Hybrid Score Formula:
Score = (weightedRSVPs × absoluteWeight) + (densityScore × densityWeight)

Density Calculation:
If square root enabled: densityScore = weightedRSVPs / sqrt(durationHours)
Otherwise: densityScore = weightedRSVPs / durationHours

Weighted RSVPs:
RSVPs before event starts count 1.0x, RSVPs after start count 0.5x

Visibility Logic:
Events are ranked by score within each city. Top N events (based on city population) are marked visible. If oversubscribed and minimum threshold is enabled, only events meeting the minimum RSVP count compete.
