How Display Overrides Work:
Display overrides let you customize how a location appears in list URLs and labels without changing the underlying database entry.
  • Users stay mapped: All existing users remain on the list - they're linked by location ID, not the key string.
  • List URI changes: The list URL will use the display key (e.g., US-NY-NewYorkCity) instead of the database key.
  • Ozone labels update: Labels emitted to Ozone will use the display key/name.
  • Database key unchanged: The original key field in the database remains the same for data integrity.
