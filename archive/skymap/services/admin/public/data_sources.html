Geoapify Data Parser

Unified parser for all countries with city boundaries, counties, and location hierarchy. Safe to re-run - updates existing cities and adds new ones.

Note: Polygon fetching is slow (API calls with delays). Only enable when needed. By default, polygons are only fetched for new cities or when missing. Use "Force refresh" to re-fetch all polygons.
