Build custom nodes for graze.social by combining locations, interests, and events.

1. Select Locations

Match posts from ANY of these locations. If you add locations, posts MUST match at least one location.

2. Select Interests

Match posts from ANY of these interests. If you add interests, posts MUST match at least one interest.

3. Select Events

Match posts from ANY event's attendees. If you add events, posts MUST be from at least one event attendee.
