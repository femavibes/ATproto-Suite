Fields with (UI Name) - Available in Graze visual editor dropdown menus
Fields without (UI Name) - JSON editor only

Core Fields

text

Post text content

Type: string
Use case: Filter by keywords, phrases, or text patterns (spam detection, topic filtering)
createdAt

ISO 8601 timestamp

Example: "2026-02-11T00:25:50.501Z"
Use case: Filter by date/time ranges, show only recent posts, exclude old content
langs
Use case: Reference full array structure in JSON

Array of language codes (ISO 639-1)

Example: ["en", "es"]
langs[*] (Language)

Individual language code for filtering

Type: string
Use case: Show only posts in specific languages, hide non-English content
tags

Array of hashtags/categories from original platform (Mastodon, RSS, etc.)

Type: array of strings • Example: ["spotify", "Real Estate"]
Use case: Filter bridged posts by original platform hashtags or RSS categories
Only present on bridged posts from Bridgy Fed
tags[*]

Individual tag from original platform (without #)

Type: string
Use case: Filter by specific hashtags from federated content (separate from Bluesky facets)
bridgyOriginalText

Original text from bridged platform (Mastodon, web, etc.)

Type: string
Use case: Access original content from federated posts before Bluesky formatting
Only present on bridged posts
bridgyOriginalUrl

Original URL from bridged platform

Type: string (URL)
Use case: Link back to original source, filter by source domain
Only present on bridged posts
$type
Use case: Identify record type for validation or type-specific filtering

Record type

Type: string • Value: "app.bsky.feed.post"
