# Quick Installation Guide

## For Users (No Technical Knowledge Required)

### Option 1: Download ZIP (Recommended)
1. Go to the [Releases page](https://github.com/YOUR_USERNAME/bluesky-moderator-extension/releases)
2. Click on the latest release
3. Download `bluesky-moderator-extension.zip`
4. Extract the ZIP file to a folder on your computer
5. Open Chrome or Edge
6. Type `chrome://extensions/` in the address bar (or `edge://extensions/` for Edge)
7. Turn on "Developer mode" (toggle switch in top right)
8. Click "Load unpacked"
9. Select the folder you extracted
10. Done! The extension is now installed

### Option 2: Direct Download
1. Click the green "Code" button on this page
2. Select "Download ZIP"
3. Follow steps 4-10 above

## Setup After Installation

1. Click the 🛡️ icon in your browser toolbar
2. You need an API key from your Feed Moderator web app:
   - Go to your web app (usually https://modmaster.fema.monster)
   - Go to Settings → API Keys
   - Click "Create New API Key"
   - Copy the key (starts with `fm_live_`)
3. Paste the API key in the extension popup
4. Enter your server URL (usually `https://modmaster.fema.monster`)
5. Click "Test Connection"
6. If successful, go to bsky.app and start moderating!

## Using the Extension

### On Posts
- Look for the 🛡️ button next to like/repost buttons
- Click it to see moderation options

### On Profiles
- Visit any profile on bsky.app
- Look for the "🛡️ Feed Moderator" panel
- Use the buttons to ban/unban users

## Troubleshooting

- **No 🛡️ buttons?** Refresh bsky.app after installing
- **API errors?** Check your API key and server URL in the extension popup
- **Still not working?** Open browser console (F12) and check for error messages

## Browser Compatibility

- ✅ Chrome (recommended)
- ✅ Microsoft Edge
- ✅ Firefox (may need minor adjustments)
- ❌ Safari (not supported)
